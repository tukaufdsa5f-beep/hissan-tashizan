# ひっさんで みる たしざん

小学1年生向けの、くり上がりのある たしざん（筆算）を アニメで見て、問題で練習できるページです。

## つかいかた
- **せつめい**：横の式から筆算になり、「10を つくる」ながれを アニメで見られます。
- **もんだい**：下の数を なにと なにに わけるか、こたえは いくつかを 数字ボタンで えらびます。
- **こたえ 10〜18 / 20〜28**：問題の はんいを えらべます。
- **はやさ**：ゆっくり / ふつう

## GitHub Pages で公開する手順
1. GitHub で新しいリポジトリを作る（例：`hissan-tashizan`）。
2. このフォルダの中身（`index.html`、`.nojekyll`、`README.md`）をアップロードする。
3. リポジトリの **Settings → Pages** で、Source を `Deploy from a branch`、Branch を `main` / `(root)` にして保存。
4. 数分後に `https://<ユーザー名>.github.io/hissan-tashizan/` で開けます。

ファイルは `index.html` 1つだけで動きます（フォントは Google Fonts から読み込み）。
